Browser + Mac, locally connected

One session.
In both places.

Pair Chrome with Glance using a local connection. Your Mac becomes the source of truth for the timer and shared settings, with no account or copied token.

Before you begin

Use Chrome on your Mac and a developer checkout with the extension preview. The native app requires macOS 14 or later. This build is ad-hoc signed, not a notarized public installer.

01 / CHROME

Load Glance Focus.

  1. Open chrome://extensions in Chrome.
  2. Enable Developer mode, then choose Load unpacked.
  3. Select the checkout's browser-extension/ folder. Pin Glance Focus in the toolbar.
  4. Add a website and approve access to it. Your browser grants its own website permissions.

You can start a standalone timer now. The Mac app is optional.

02 / GLANCE

Enable the Mac connection.

From the repository root, build and open the app bundle:

make app
open dist/Glance.app

In Glance Settings, open Browser Focus and choose Enable browser connection. This registers the bundled helper with Chrome in your user account.

If you rebuilt Glance, quit the older running app before opening the new bundle.

03 / PAIR

Connect and approve.

  1. Open the extension and choose Connect to Glance.
  2. Approve the pairing dialog in the Mac app.
  3. Confirm the extension says Connected to Glance.
  4. Choose Open web dashboard in the extension to explicitly allow the hosted dashboard to access local state.

What stays in sync.

The Mac owns the timer.

Phase, run state and deadline follow Glance. Browser Start uses the app's configuration; a stale browser duration never replaces it.

Settings live on your Mac.

Website rules, exclusions and desired tracking settings are stored in the app. Each browser still needs its own permission grants.

Reloads reconnect.

The extension reconnects after a reload and retries while the app is unavailable. It preserves the last confirmed deadline.

Standalone is explicit.

Choose Use standalone to run a browser-owned session. After the Mac app quits and restarts, its timer returns to idle and Chrome follows.

If something needs a nudge.

Chrome says the native messaging host was not found.

Open the rebuilt Glance app. In Settings → Browser Focus, choose Enable browser connection or Repair browser connection, then reconnect in the extension.

The native connection API is unavailable.

Reload Glance Focus at chrome://extensions, reopen the popup and connect again. Native Messaging is declared when the extension is installed.

The timer or settings look stale.

Check that the extension says Connected to Glance and that you opened the rebuilt app. Pairing adopts the Mac's session, including its idle state. The Mac remains authoritative during a connection.

The hosted dashboard asks me to connect.

Open Glance Focus and choose Open web dashboard to allow local access. A regular localhost page is intentionally not authorized to read native state.

Ready when you are.

Your browser, your Mac, one focus session.
