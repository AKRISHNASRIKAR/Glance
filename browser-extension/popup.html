          Local setup and privacy

          Load this folder unpacked from chrome://extensions. Run the native host installer described in README.md, open the rebuilt Glance app, then approve pairing in Glance. This development build does not install a native helper by itself.

          Website permissions are requested when you add a domain. Usage stats request tab metadata and idle permission separately. Blocking continues when usage tracking is off. Nothing is uploaded to Glance servers.

          One Chrome profile is one local installation. Mac connection can mirror its timer but does not make different browser profiles one timer. Disabling the extension bypasses blocking.
