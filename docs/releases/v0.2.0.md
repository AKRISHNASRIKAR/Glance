# Glance 0.2.0

## Browser Focus companion support

- Add Browser Focus to Mac settings, with explicit approval for each Chrome profile.
- Bundle the local Native Messaging helper with Glance.
- Make the Mac authoritative for the paired Pomodoro timer, deadline and shared browser preferences.
- Store paired website rules and optional domain-level activity locally on the Mac, with 30-day activity retention.
- Validate local requests and reject replayed commands and stale preference writes.

The Chrome extension remains a separate developer preview. This app release does not install the extension or publish it to the Chrome Web Store. Browser Focus is optional; the app continues to work independently.

## Validation

Native tests cover timer deadlines, shared preferences, statistics validation, retention, deduplication and protocol handling. The app bundle includes both the main executable and GlanceBrowserBridge.

Signing and notarization depend on the release environment. An ad-hoc build is an unsigned preview, not a notarized distribution.
